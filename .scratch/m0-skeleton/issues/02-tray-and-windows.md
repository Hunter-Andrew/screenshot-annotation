# Tray icon, single instance and hidden editor window

Status: ready-for-agent
Blocked by: 01

On launch:
- Show a tray icon; left-click shows the (empty) editor window.
- Right-click menu: Open editor · Settings · Exit. Capture items are added in M1.
- **Single instance:** a second launch focuses the existing app.
- **Editor window:** created at startup hidden. Closing it hides it rather than quitting; Exit quits.

**Done when:** these behaviors work on Windows.
