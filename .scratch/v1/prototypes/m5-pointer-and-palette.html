M5 prototypes: desktop pointer and colour palettes

These are throwaway prototypes for tickets 40 and 42. The pointer is red in every option. The cursor is hidden inside each pointer box so you only see the option.

Pointer: pick a look

Each one follows the mouse over the whole desktop and lets clicks pass through.

Palette: pick one

Green is the main accent: selected tool, Copy and the selection outline. Purple #520DF2 is the second accent: section headers, toggles and the Library Strip selection. #520DF2 is too dark to read on a dark background, so the dark theme needs a lighter tint for purple text. The options differ in which green they use and how that tint is handled. Each option is shown in dark and light.
